# ShareIt - сервис шеринга вещей

## О проекте

ShareIt — это сервис, который позволяет пользователям делиться своими вещами, брать вещи в аренду, оставлять отзывы и создавать запросы на нужные вещи. Проект реализован в рамках учебного курса по Java-разработке.

## Технологический стек

- **Java 21**
- **Spring Boot 3.2.0**
- **Spring Data JPA**
- **Spring MVC**
- **PostgreSQL**
- **H2 Database** (для тестов)
- **Maven** (многомодульный проект)
- **Lombok**
- **Docker**

## Архитектура проекта

Проект разделен на два модуля:

### Gateway (порт 8080)
- Отвечает за валидацию входных данных
- Принимает запросы от пользователей
- Перенаправляет запросы к Server модулю

### Server (порт 9090)
- Содержит основную бизнес-логику
- Работает с базой данных
- Обрабатывает запросы от Gateway

## Функциональность

### Пользователи
- Создание, редактирование, просмотр и удаление пользователей
- Валидация email и имени

### Вещи
- Добавление новых вещей
- Редактирование информации о вещи
- Просмотр вещей по ID
- Просмотр всех вещей пользователя
- Поиск вещей по названию и описанию
- Возможность указать ID запроса при создании вещи (ответ на запрос)

### Бронирования
- Создание запроса на бронирование
- Подтверждение/отклонение бронирования владельцем вещи
- Просмотр бронирований (своих и вещей)
- Фильтрация по статусам: ALL, CURRENT, PAST, FUTURE, WAITING, REJECTED

### Комментарии
- Добавление отзывов на вещи после завершения аренды
- Просмотр отзывов при просмотре вещи

### Запросы вещей
- Создание запроса на нужную вещь
- Просмотр своих запросов с ответами
- Просмотр запросов других пользователей
- Просмотр конкретного запроса
- Сортировка от новых к старым

## API Endpoints

### Пользователи (`/users`)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/users` | Создание пользователя |
| PATCH | `/users/{userId}` | Обновление пользователя |
| GET | `/users/{userId}` | Получение пользователя по ID |
| GET | `/users` | Получение всех пользователей |
| DELETE | `/users/{userId}` | Удаление пользователя |

### Вещи (`/items`)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/items` | Добавление вещи |
| PATCH | `/items/{itemId}` | Обновление вещи |
| GET | `/items/{itemId}` | Получение вещи по ID |
| GET | `/items` | Получение вещей текущего пользователя |
| GET | `/items/search` | Поиск вещей |
| POST | `/items/{itemId}/comment` | Добавление комментария |

### Бронирования (`/bookings`)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/bookings` | Создание бронирования |
| PATCH | `/bookings/{bookingId}` | Подтверждение/отклонение |
| GET | `/bookings/{bookingId}` | Получение бронирования |
| GET | `/bookings` | Получение бронирований пользователя |
| GET | `/bookings/owner` | Получение бронирований вещей пользователя |

### Запросы (`/requests`)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/requests` | Создание запроса |
| GET | `/requests` | Получение своих запросов |
| GET | `/requests/all` | Получение запросов других пользователей |
| GET | `/requests/{requestId}` | Получение запроса по ID |
